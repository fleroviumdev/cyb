● IPv4 Datagram Header: Structure of the packet used in IPv4 communication.
● Layer 2 vs Layer 3 Addressing: Layer 2 uses MAC addresses; Layer 3 uses IP addresses.
● Address Resolution Protocol (ARP): Maps Layer 3 IP addresses to Layer 2 MAC addresses.
● Unicast Addressing: One-to-one communication.
● Broadcast Addressing: One-to-all communication within a network.
● Multicast Addressing: One-to-many communication to interested hosts using special IP ranges.
● Anycast Addressing: One-to-nearest communication, used by routers and protocols like BGP.
Public vs Private Addressing
● Public IPs: Routable on the internet, managed by IANA.
● Private IPs: Reserved for internal use, non-routable on the internet.
● Class A: 10.0.0.0 to 10.255.255.255
● Class B: 172.16.0.0 to 172.31.255.255
● Class C: 192.168.0.0 to 192.168.255.255
Other Reserved Address Ranges
● Class D: 224.0.0.0 to 239.255.255.255 (Multicast)
● Class E: 240.0.0.0 to 255.255.255.255 (Experimental)
● Loopback: 127.0.0.0 to 127.255.255.255

● ipconfig: Windows tool for viewing and managing IP configuration.
● ifconfig and ip: Linux tools for network configuration.
● arp: Displays and modifies IP to MAC address mappings.
● ping: Tests connectivity using ICMP echo requests.

ipconfig Commands
● ipconfig (basic)
● ipconfig /all (detailed info)
● ipconfig /renew, /release (DHCP control)
● ipconfig /flushdns (clear DNS cache)
● ipconfig /registerdns (register DNS)

ifconfig and ip Commands
● ifconfig (deprecated but still used)
● ip addr, ip link, ip -s link (modern commands for IP and interface info)

arp Commands
● arp -a (Show ARP table)
● arp -s (Add static ARP entry)
● arp -d * (Delete all ARP entries)
● ip neigh (Show neighbor table)

IPv6 Unicast Addressing
● Global unicast and Interface ID (EUI-64).
IPv6 Link Local Addressing
● Automatically configured addresses for local network communication.
IPv6 Multicast and Anycast Addressing
● Multicast uses protocols like MLD.
● No broadcast in IPv6.
● Neighbor Discovery (ND) protocol replaces ARP.
● Anycast used for nearest-node communication.
IPv4 and IPv6 Transition Mechanisms
● Dual stack, tunneling, and NAT64 to support coexistence.
Common IPv6 Address Prefixes
● Global unicast: 2000::/3
● Link local: fe80::/10
● Multicast: ff00::/8
● Loopback: ::1/128
● Documentation examples: 2001:db8::/32


LESSON 4.1 Internet Protocol Basics

In which scenario would a host use broadcast addressing?
--- When attempting to discover all hosts within its local network or subnet.

​Routing data between computers on a network requires several mappings between
different addresses.
Which of the following statements is true?
--- Hosts use ARP to resolve known IP addresses into MAC addresses.

What is the function of the Protocol field in the IPv4 header?
--- Specifies the type of data encapsulated in the payload

What is the maximum theoretical size of an IPv4 packet?
--- 65,535 bytes

What is the primary difference between unicast and broadcast addressing?
--- Unicast addressing sends data to a single recipient, while broadcast
addressing sends data to all recipients within a network.

What is the primary function of forwarding at Layer 3 in a network?
--- Routing packets based on IP addresses

What role does a router play in a network with multiple subnets?
--- It forwards packets between subnets.

Which of the following allows the same IP address to be assigned to multiple
interfaces?
--- Anycast

Which of the following statements accurately describes the use of ARP messaging
in network communication?
--- ARP messaging is used with both Ethernet and Wi-Fi networks to resolve IP
addresses to MAC addresses.

Which type of address is the IP address 232.111.255.250?
--- Multicast

LESSON 4.6 IP Troubleshooting

How can you identify machines with duplicate IP addresses?
--- Using ping and then arp -a to examine the ARP cache table

In a subnet with a /28 mask, why can't you rely solely on the first three octets
to determine if an IP address is within the same subnet?
--- Because the network prefix boundary lies within the last octet

What does successfully pinging the IP address of the default gateway verify?
--- That you can communicate with another host on the local network

What is a likely cause of duplicate MAC addresses on a network?
--- Use of locally administered addressing

What is the first step in the general ping sequence for identifying connectivity
issues?
--- Ping the loopback address.

What is the first step in troubleshooting IP configuration issues if you have
ruled out problems at the Physical and Data Link layers?
--- Use ipconfig or ifconfig to verify the host configuration.

What issue arises when a host has an incorrect subnet mask that is longer than
it should be?
--- The host misroutes its replies, thinking communicating hosts are on a
different subnet.

What should you suspect if you cannot ping a local host and the error is
"destination unreachable"?
--- Incorrect IP address or netmask in the IP configuration

Why might pinging remote hosts fail even if the network configuration is
correct?
--- ICMP is blocked by a firewall or other security software.

You are monitoring network traffic and notice that ARP requests for a specific
IP address are receiving responses from two different MAC addresses.
What is the MOST likely cause of this issue, and how should you proceed to
troubleshoot it?
--- The IP address is configured on a virtual machine and its host; reassign the
IP address to only one device. 

Vocabulary
● Address Resolution Protocol (ARP): A protocol used to map an IP address to a physical machine (MAC) address on a local network.
● Anycast Addressing: A network addressing method where data is routed to the nearest or best destination out of a group of potential receivers.
● Broadcast Addressing: Sending data to all devices on a local network segment.
● Classful Addressing: The original system dividing IP addresses into fixed classes (A, B, C, D, E) based on address ranges.
● Classless Inter-Domain Routing (CIDR): A method for allocating IP addresses and routing that replaces the classful system with flexible prefix lengths.
● Default Gateway: A network device that routes traffic from a local network to other networks or the internet.
● DHCP (Dynamic Host Configuration Protocol): A protocol that automatically assigns IP
addresses and other network configuration to devices.
● Duplicate IP Address: When two devices on the same network have the same IP address, leading to conflicts.
● EUI-64: A method for automatically generating an IPv6 Interface ID using a device’s MAC address.
● Flow Label: A field in the IPv6 header used to identify packets requiring special handling.
● Host Address Range: The set of valid IP addresses that can be assigned to devices on a subnet.
● ICMP (Internet Control Message Protocol): Used by network devices to send error
messages and operational information.
● Interface ID: The portion of an IPv6 address that identifies a specific interface on a subnet.
● IPv4 (Internet Protocol version 4): The fourth version of the Internet Protocol, using 32-bit addresses.
● IPv6 (Internet Protocol version 6): The newest Internet Protocol version, using 128-bit addresses.
● Link Local Addressing: IPv6 addresses automatically assigned for communication within
the local network segment.
● Loopback Address: An IP address (127.0.0.1 for IPv4, ::1 for IPv6) used by a host to send packets to itself.
● MAC Address (Media Access Control Address): A hardware address that uniquely
identifies each device on a local network.
● Multicast Addressing: Sending data to a group of interested receivers.
● Network Mask / Subnet Mask: A binary mask used to identify the network portion of an IP address.
● Neighbor Discovery (ND): Protocol in IPv6 that replaces ARP to find other devices on the local network.
● Prefix (Slash) Notation: A shorthand for writing IP network masks indicating the number of bits used for the network.
● Private IP Address: IP addresses reserved for use within private networks, not routable on the internet.
● Public IP Address: IP addresses that are routable on the internet.
● Routing Table: A data table stored in a router or host that lists routes to particular network destinations.
● Subnet: A logically visible subdivision of an IP network.
● Subnetting: The process of dividing a network into smaller subnetworks.
● Tunneling: A method used to send IPv6 packets over an IPv4 network.
● Variable Length Subnet Mask (VLSM): Allows subnets to have different sizes by using
different subnet masks.
● Unicast Addressing: One-to-one communication between a single sender and a single
receiver.
